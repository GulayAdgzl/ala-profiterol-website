# Ala Profiterol Coffee Website

A responsive one-page website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser, but Live Server is recommended.

## Project structure
- `index.html` — page sections and content
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation and active section state
- `assets/images/` — supplied business photos and design references
